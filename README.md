#  CropSetu — Bridging Crops to Better Markets

**CropSetu** is a farmer-focused digital platform concept designed to bridge the gap between farmers and better markets. Its goal is to help farmers discover market opportunities, explore mandi prices, and make more informed selling decisions.

> **Tagline:** From Farm to Fair Price.

##  About the Project

Farmers often face challenges in finding suitable markets, understanding crop prices, and connecting with potential buyers. CropSetu aims to simplify this process through an accessible, agriculture-focused digital platform.

The project is currently in its **initial UI development and prototyping phase**. The first interface has been started using Lovable, with a mobile-first layout and a green agriculture-inspired design.

##  Features & Current Progress

###  Implemented / Initial UI Created

- **Location Selector** — UI for selecting a location.
- **Search Bar** — Initial search interface for discovering relevant information.
- **Quick-Access Tiles** — Five shortcut tiles for easy navigation.
- **Mandi Prices Section** — UI section for displaying crop market prices using demo data.
- **Bottom Navigation** — Navigation layout for accessing key areas of the application.
- **Responsive Design Direction** — Mobile-first interface with an agriculture-inspired green theme.
